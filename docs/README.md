# docs/ — Conocimiento por tema

A diferencia de `BITACORA.md` (cronológica), aquí el conocimiento se organiza **por tema** para
poder consultarlo sin recorrer la historia.

- **`frentes/`** — Un archivo por cada frente de trabajo (área real: C#/.NET, automatizaciones,
  integraciones, etc.). Plantilla: [`../plantillas/ficha-frente.md`](../plantillas/ficha-frente.md).
- **`capacidades/`** — Fichas de capacidades de Claude Code que vamos probando (subagentes, hooks,
  MCP, skills…). Plantilla: [`../plantillas/ficha-capacidad.md`](../plantillas/ficha-capacidad.md).
- **`guias/`** — Cómo-hacer reutilizables (procedimientos paso a paso).
