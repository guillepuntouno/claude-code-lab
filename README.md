# claude-code-lab

Laboratorio personal para **explorar y documentar** las capacidades de Claude Code como agente
de código en distintos frentes de trabajo.

## Cómo navegar este repo

| Ruta | Qué encontrarás |
|------|-----------------|
| [`BITACORA.md`](BITACORA.md) | Diario **cronológico**: qué se hizo, cómo y por qué (decisiones). |
| [`docs/`](docs/) | Conocimiento **por tema** (no cronológico). |
| [`docs/frentes/`](docs/frentes/) | Una ficha por cada frente de trabajo. |
| [`docs/capacidades/`](docs/capacidades/) | Fichas de capacidades de Claude Code probadas. |
| [`docs/guias/`](docs/guias/) | Cómo-hacer reutilizables. |
| [`scripts/`](scripts/) | Scripts reutilizables, documentados. |
| [`experimentos/`](experimentos/) | Pruebas desechables, una carpeta por experimento. |
| [`plantillas/`](plantillas/) | Plantillas base reutilizables. |

## Idea clave

- **`BITACORA.md`** responde *"¿qué pasó y por qué?"* → cronológico.
- **`docs/`** responde *"¿cómo funciona X?"* → temático.

Son complementarios: la bitácora enlaza a los docs.

## Convenciones

- Fechas en formato `AAAA-MM-DD`.
- Español como idioma de trabajo.
- **Sin datos sensibles:** este repo es público. No se commitean correos, tokens, rutas
  internas ni credenciales (ver [`.gitignore`](.gitignore)).
