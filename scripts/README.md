# scripts/

Scripts reutilizables que surjan de los experimentos (bash, PowerShell, Python…).

**Regla:** cada script debe estar documentado aquí con:

| Script | Qué hace | Cómo se usa |
|--------|----------|-------------|
| _(ejemplo)_ `saludo.sh` | Imprime un saludo | `bash scripts/saludo.sh` |

_Aún sin scripts._
